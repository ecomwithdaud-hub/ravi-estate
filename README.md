# Ravi Estate (`raviestate.com`)

> **"Deals in all kinds of properties."**

Full-stack **Next.js (App Router)** and **Tailwind CSS** web application for **Ravi Estate** featuring two integrated modules:

1. **Public-Facing Marketing Website & Portfolio** (`/`)
   - **Flagship International Project Spotlight**: *Value Apartments – Madina Al Munawwarah (Wadi Mubarak)* by Value Group (10-minute proximity to Masjid an-Nabawi, Haramain High-Speed Railway Station access, 8 km from Madinah International Airport, smart living amenities, interactive brochure reader, and direct PDF brochure generator).
   - **Pakistani Portfolio Track Record** (Value Group Partnership):
     - Green View Executive Apartments *(DHA Phase 5, Lahore)*
     - Value Apartments *(PECO Road, Link Road, Model Town Lahore)*
     - Value Residencies *(Barki Road, Opposite DHA Phase 8 Lahore)*
     - Green View Smart Homes *(DHA Phase 12 EME)*
     - Corporate Tower *(Gulberg, Lahore)*
     - Value Lahore Organic Farmhouses *(Barki Road, Lahore)*
   - **Investor Lead Capture Form**: Real-time sync with the Internal CRM Pipeline.

2. **Internal CRM Pipeline Dashboard** (`/crm` or via top-bar Module Switcher)
   - Role-based view switcher (*Sales Manager*, *KSA International Desk*, *Lahore Advisory*).
   - Live KPI Analytics Header (*Total Inbound Leads*, *Conversion Rate*, *Active International Leads (Madina Project)*, *Total Pipeline Value*).
   - Interactive 4-stage Kanban board (*New Leads*, *Contacted / Qualified*, *Virtual/In-Person Consultation Scheduled*, *Deal Closed / Won*) with drag-and-drop and click-to-advance controls.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
